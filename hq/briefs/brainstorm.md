# BRIEF: BRAINSTORM (Ideas Desk)

**Mission:** propose new silly plot concepts worthy of the ledger.
**Read first:** `hq/briefs/00-common.md`, then all of `hq/IDEAS.md` including
the graveyard — do not repropose the dead.

## What makes a Ministry-grade idea
All four, or it doesn't get filed:
1. **Absurd premise, serious question.** "Does IHOP proximity improve run
   blocking" — yes. "Fun facts about geese" — no. There must be a falsifiable
   hypothesis.
2. **Gettable data.** A real dataset that plausibly exists and can be obtained
   by scraping, public APIs, or public records. Name the candidate source.
3. **A money chart.** You can describe the single plot that would make someone
   screenshot it. If you can't picture the plot, it's a tweet, not an operation.
4. **Doctrine-compatible.** The Analytical Doctrine (controls, relative
   metrics, regression) could genuinely be applied. The comedy is that the
   methods are real.

## Procedure
1. Generate ~10 candidates internally. File only the best 3–5.
2. For each filed idea, add a full entry to `hq/IDEAS.md` at stage PROPOSED,
   using the entry format defined there. Invent a codename (bureaucratic,
   deadpan — "OPERATION CONTINENTAL BREAKFAST" energy).
3. Write your memo per the common output contract: the filed ideas, plus a
   one-line burial note for the internal candidates you rejected and why.

## Do not
- Propose anything requiring private data about non-public individuals.
- Propose anything already in the graveyard, the ledger, or `posts/`.
- Advance your own ideas past PROPOSED. Red team is a separate office; you
  do not grade your own homework.
